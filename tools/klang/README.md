## Why it is needed

The VS Code extension's **Run Current File** and `klangb --run` go through the browser bridge. That bridge caps each message at 1 MiB. MiniTS compiles to a program larger than that, so a bridge run prints nothing and ends with:

```
execution-failed: Bridge messages must not exceed 1048576 UTF-8 bytes.
```

Running the compiler directly with Python has no such limit.

## Usage

Needs Python 3.12+ and no other packages. Run it from the folder that holds the `.kl` files, so that `include` paths resolve:

```bash
cd minits-project1-pure-hm
python -I ../tools/klang/klang-browser.py --run -d pure-hm tests.kl      # about 40 s, 242 tests

cd ../minits-project1-func-hm
python -I ../tools/klang/klang-browser.py --run -d func-hm tests.kl

cd ../minits-project1-func-dynamic
python -I ../tools/klang/klang-browser.py --run -d func-dynamic tests.kl

cd ../minits-hope-twists/ternary
python -I ../../tools/klang/klang-browser.py --run -d pure-hm tests.kl
```

Other options are the same as for `klangb`: leave out `--run` to only compile, and use `--emit-ir` to print the IR. `-o FILE` writes the generated Python.
